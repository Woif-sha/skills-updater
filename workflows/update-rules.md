# Record Or Update A Rule

Use this only when task closure finds a reusable, non-obvious lesson with material recurrence cost.

1. Search `rules/`, `workflows/`, and `references/` before writing.
2. Update the closest existing entry; create a file only when no routed destination fits.
3. Put invariants in `rules/`, ordered actions in `workflows/`, and pitfalls or code maps in `references/`.
4. Give every new reference an activation path from `routing.yaml`, a routed workflow, or an always-read rule.
5. Keep session history in Git, not active Skill documentation.
6. Re-run route, orphan, link, and size checks; remove obsolete wording in the same change.
